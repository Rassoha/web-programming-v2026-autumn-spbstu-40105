# Лабораторная работа 5

## Задание

Вариант 8.


Создайте приложение для бронирования билетов на фильмы. Приложение
должно включать:
- Список фильмов с основной информацией (постер, название);
- Форму бронирования с валидацией данных;
- Подтверждение бронирования.
Функциональность:
- просмотр списка фильмов;
- выбор фильма → переход к форме бронирования;
- заполнение формы с валидацией;
- Отправка формы (имитация) → показ подтверждения.
Примечание: Обязательные поля: Имя, Email, Телефон. Дополнительные
поля: Дата сеанса, Время, Количество билетов, Тип билета.
